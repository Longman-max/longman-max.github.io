# Updating your status

Edit `public/status.json` directly and push to your repo.
No rebuild required — GitHub Pages serves the file statically.

Fields:
- last_updated: ISO date string, e.g. "2026-06-24"
- building:     what you're currently building
- reading:      book or paper you're going through
- location:     where you are
- status:       one line on availability — this renders highlighted in indigo

Keep values under ~55 characters to avoid line wrapping in the terminal block.
